# 转盘速度与原生素材验收 v24

## 转盘交互

×1、×2、×4分别为转动速度，不改变盘面尺寸。普通动效时长分别为3.9秒、1.95秒、0.975秒；简化动效时长分别为0.45秒、0.225秒、0.1125秒。统一应用到11个建档项目、日常锻炼、矢量突破对手与分级转盘。

转盘保留末段减速，同一抽取结果在各速度下停在同一位置。开始转动时固定本次时长，结果揭晓与动画同步；转动中禁用速度切换。速度保存在浏览器，独立于简化动效设置，不改变战斗、领袖入场或成长动画时长。

密集盘面另设“放大读字”按钮，可放大并滚动查看；还原后恢复正常尺寸。该功能与速度按钮分开，完整选项仍在列表中。

## 原生素材

从用户提供的[PRTS文件一览](https://prts.wiki/w/PRTS:文件一览#团队LOGO)实际团队与阵营目录选取9个原生标志：罗德岛、精英干员、龙门近卫局、企鹅物流、莱茵生命、格拉斯哥帮、深池、巴别塔、岁。

素材本地保存于`dist/assets/prts/factions/`，精确来源、文件大小、哈希与权属说明在该目录`sources.json`。保留原有透明度及阵营标志细节，黑色团队标志在深色界面转为白色。

应用位置包括首页、博士档案、图鉴原型、主线节点、战前简报、战斗人物卡及领袖入场背景。博士使用罗德岛标志；图鉴使用技能原型所属团队。采用明确原型映射，未匹配单位保留职业符号，不将借用源石技艺解释为博士改变阵营，也不为召唤物强行添加阵营。
