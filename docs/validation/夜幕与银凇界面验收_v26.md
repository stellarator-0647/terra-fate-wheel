# 夜幕与银凇界面 v26

## 本轮实装

- 首页创建身份、介绍、默认输入及空名称回退统一为“穿越者”。旧档默认名“博士”在首页摘要显示为“穿越者”，自定义姓名不变。
- 《生命流》随网站本地部署，默认25%音量、循环播放。第一次点击或键盘操作后启动；音乐开关、音量、错误重试、后台暂停和返回恢复独立于游戏存档。
- 首页使用夜幕原生场景；游戏内容使用始发原生场景配合银凇的银白、青色和几何分隔。图鉴、转盘、档案、准备日、作战、成长和旅程结局统一重做。
- 转盘保留彩色全部扇区、机械盘沿、清晰银白盘心、指针和末段减速。选项列表独立展示权重，速度开关仍仅影响速度。
- 角色和档案使用浅色数据块；敌方使用低饱和红色。手机行动按钮改为两行三列，正文使用面板内部滚动，避免挤压战斗操作区。
- 修复存档导入控件未挂到文档的问题，支持真实文件选择和导入后清理。

## 设计依据

阅读并查看了 [PRTS界面主题一览](https://prts.wiki/w/界面主题一览) 中的夜间/夜幕与银凇/始发预览。提取夜幕的深色菜单块、明亮操作标记，以及银凇的银白留白、青色几何构图与细分隔线。场景由PRTS原图提供，文件、来源和权属记录在 `dist/assets/prts/themes/sources.json`；不是重新绘制的仿制插画。

使用用户指定 potatoDesignSkill 的任务路径、信息层级、中文可读性、触控尺寸和动效检查原则。主路径仍是建立档案→准备日→作战→成长→终章；同一青色只承担我方信息与主要操作，红色只承担敌方信息与威胁。

## 验收证据与范围

完整124项自动回归通过，包括音乐首次交互、坏设置、后台恢复、异步关闭及重试，既有转盘概率、战斗、技能和连续控制测试。另执行应用入口JavaScript语法检查。

实际浏览器确认：首次操作后音乐readyState=4、paused=false、时间持续前进，音频仅有一个实例。实际点击A技能后，技力扣减和“息”资源更新到1/3，队友继续自动行动。

1366×900桌面和390×844手机检查了布局。手机无横向溢出，六个行动按钮约113×49像素且全部位于视口内；敌我阵列、技能、档案与记录拥有独立滚动区域。长技能可在描述区滚动阅读，不要求把所有长文本塞入一屏。修复检查中发现的浅色角色卡低对比文字与技能正文高度不足问题。

成长和终章通过独立展示存档检查：成长数字、提升量、评级、终章正文、Boss战果、模式叙述与记录均可阅读。展示存档包含脚本设置的胜利，仅用于验证页面；不作为实战通关或数值平衡证据。本轮没有更改伤害、成长、隐藏池概率或战役数据。

音乐来源：[MSR官方《生命流》](https://monster-siren.hypergryph.com/music/232202)，主页场景关联见[首页场景一览](https://prts.wiki/w/首页场景一览)。
