# 结局档案与一人成军 v25

## 游戏流程

新建旅程选择规则 → 转盘建档 → 日常准备与矢量突破 → 主线作战 → 战果与成长归档 → 下一场行动 → 节点收束 → 完整旅程档案。

保留原有铁人、传奇之路、连贯战役和独立节点选项；新增可叠加的“一人成军”。规则在开局选择，存档中保存。

## 一人成军

- 全部48场后续主线战斗不编入剧情NPC队友。源石技艺产生的召唤物与任务设施正常工作；博士阵亡后，存活的战斗召唤物仍可完成目标。
- 五项初始战力仍各自独立抽取。B−及以上从约29%升至66.5%，A−及以上从约8.5%升至26.5%。源石技艺池与成长天赋概率不随此规则变化。
- 高阶稀有度继续递减：S−2%、S0.8%、SS−0.4%、SS0.2%、SSS−0.07%、SSS0.02%、SSS+0.01%。低值仍有可能，模式不是保证通关。
- 核心塔决战和心象终局的协同路线改为博士每轮防御或休整累积1点，共6点，且坚持至第8轮。其余击败敌人、破坏设施等路线保留。心象终局中博士不再享有由队友牵制支撑的不可选中保护，避免空阵列无风险完成。
- 开局、转盘概率表、战前队伍、战斗阵列、档案和结局叙述同步体现该规则。

## 结局内容

结算分为终章记述、模式经历、领袖战果、成长对比、战术与日常、旅程刻印、完整行动时间线。保留档案导出与返回标题，首尾均有明确入口。

终章串联出生地、种族、感染身份、穿越起点、源石技艺原型、抵达路线、完成任务、成长、最强击败记录和最后遭遇。12个节点各有对应的收束文字；成功、撤离与铁人覆灭使用不同结尾。铁人、传奇之路、一人成军、重试和战后救援均按实际经历叙述，传奇模式未抽中隐藏能力时也会如实说明本次相遇的能力。

### 战果规则

记录的是游戏内实际交锋，不替代原作人物命运。

- **战场击败**：首领最终生命归零，战斗引擎已记录其倒下；阶段复起不计入最终击败。
- **强制退场**：首领被移出阵列，仍有生命，不计入击败数。
- **目标达成·未击败**：首领仍存在，但完成撤离、破障、坚持等任务。
- **未解除**：任务未完成，首领仍存活。

局部分体与心象交锋单独标明。重复尝试的同一遭遇只保存一个最优战果，完成作战按唯一遭遇统计；行动次数、耗材及失败尝试按实际出战累加。完成剧情目标时，若确实击败了其中一名首领，这份击败记录仍保存，不以任务类型覆盖真实结果。

### 值得留下的记录

六项能力从初始到最终的绝对增长与最终分级；熟练度、专精/升变时点；博士各类有效行动次数；正式作战我方实际生命伤害、护盾伤害、有效治疗、消耗补给、召唤部署、设施破坏、场景炮击、身份核验；准备日、最常锻炼项目、矢量突破成败；同行人物、战后获救、重试和未完成任务。

旅程刻印依据已核实经历解锁，包括完整的一章、铁人行路、一人成军、强敌回声、专精/升变、突破者、战后获救、成长到王庭之主。不会把仅仅开启模式当成通关成就。

旧存档可以继续。初始属性可从原始转盘结果恢复；过去没有保存的Boss退场、详细行动与伤害不会补造，页面标注记录不完整，从更新后的作战开始积累。

## 视觉设计与可用性

借鉴[PRTS集成战略](https://prts.wiki/w/集成战略)的探索成果归档思路，以章节封面、模式标签、纸面终章、金色刻印、战果名册和能力对照表达一段旅程。保留原生罗德岛标志，继续使用全站的PRTS终端色系；界面和文字为本游戏设计，没有搬用集成战略评分公式或通关结论。

电脑采用正文与模式叙述双列、能力三列；手机改为单列正文、能力双列。关键按钮在手机至少44像素高。进入结局时定位到页首，时间线使用明确的可展开标题，动画不承载必读信息。
