# 玩家身份与原生标志更新 v24.1

博士不再判定为领袖：人物卡不显示“我方领袖”，入场不触发领袖动画。即便旧存档有领袖字段、借用领袖或Boss的源石技艺，玩家仍被排除。剧情领袖、Boss及召唤物的既有分类继续有效。

左上角图标与浏览器图标统一替换为PRTS原生罗德岛标志。素材文件为`dist/assets/prts/factions/rhodes.png`，沿用此前从PRTS实际素材目录选取并核验的文件，来源记录在该目录`sources.json`。

验收：13项针对性回归通过；浏览器实测战斗开始直接展示敌方陈的领袖入场，博士卡没有领袖标签。首页与敌方入场截图在`artifacts/v24.1/ui/`，日志在`artifacts/v24.1/tests.txt`。本次不改变战斗数值与技能。
