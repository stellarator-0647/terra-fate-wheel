# 团队胜利与动画验收 v22

2026-10-02。

## 胜负与联动

- 博士阵亡／退场不再立即失败。仍存活的友方主体与独立召唤物自动行动，玩家进入观战；保留暂停、单位查看与撤离操作。
- 全队战斗单位退场且敌方未全灭才判全队覆灭；设施、0生命中继不能代替战斗单位。最后一击自毁并杀死全部敌方仍成功。剧情护送完整度、设施和期限等失败条件仍生效，不因博士阵亡而取消。
- 友方主人真正死亡后，独立召唤物保留现有属性与攻击模式；剩余持续机会转为自身机会倒数。已设真实到期时刻的临时流形继续遵守原时刻；自毁与自扣血仍生效。绑定设施和中继按原规则清理；强制退场仍清理其所有附属单位。敌方主人死亡清理机制保持现行设定。
- 主人死亡不再禁止这些独立召唤物攻击。召唤物到期退出不触发击杀；保命、复活、Boss阶段与黑棺封存解除继续先按原规则处理。封存友方不冒充死亡。
- 剧情团队胜利照常获得五项成长与熟练度。博士经战后救援恢复新生命上限的30%（向下取整，至少1），下一场可以正常行动；这不是战斗内复活，不能反复消耗一次性复活次数。矢量训练仍恢复训练前正式生命，不携带训练损耗。
- 默认铁人模式文案改为全队覆灭结束旅程。尚未结算、仅因旧“博士倒下”判负且友方仍活着的存档可恢复战斗；已结束整局／已清除快照的旧失败不伪造回溯或补发奖励。

## 动画设计

目标：让玩家一眼分清作战接入、博士退场、团队胜利和正式归档，同时读得到任务、意图与技能费用。

流程：开场接入 → 单位行动／技能轨迹 → 博士退场观战（可被战内合法复活中断） → 胜负展开 → 成长数字／倍率 → 下一场或终局归档。

| 场景 | 实装 |
|---|---|
| 开场 | 1.2秒几何徽记、扫描栅格、切片展开；阵列逐步揭示 |
| 技能 | 保留全部技艺通用轨迹，12类专属法阵／陨石／缝线／时钟／星轨等，5组社区彩蛋 |
| 阵亡 | 单位灰化并标注已退场；命令区显示观战；顶栏短提示 |
| 胜负 | 850毫秒双菱形、山形线条与任务文字展开；团队胜利标注战后救援 |
| 胜利成长 | 六项旧值→新值与增幅、条形伸展、熟练度突破；成长已经保存 |
| 结局 | 同风格归档印记、历史记录展开；全队覆灭使用失败配色与文字 |

配色沿用深蓝终端底色#0a1e2b、浅字#eaf3f6、接入青#94d4e2、成功浅绿#c6dbaa、失败柔红#d59598。中文系统字体，标题24—30px，补充信息12—13px。SVG图形为原创几何符号，无搬运音频或原画。特效层pointer-events:none，不夺焦点、不改变结算。短状态提示放在顶栏，避免遮住任务段落；减少動效／系统减少动态偏好抑制粒子和过渡。
