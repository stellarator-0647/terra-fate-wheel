# 泰拉命运转盘 v22.2 · 准备与战斗界面

## 本次完成

1. 每日项目结算后生命回满，按成长后的最新生命上限计算。矢量突破在胜负结算后回满；剧情战斗间仍按原战役规则保留生命。
2. 删除每日转盘中的医疗休养。现有七项按剩余权重重新归一化，没有新增替代休养项。
3. 档案六项战斗数值显示对应分级。战斗面板使用简短中文与字母分级，完整名称和分级可在“详情”中查看。生命用生命上限÷12换算，技力分级跟随源石技艺适应性，成长、感染身份和战内属性变化计入显示。
4. 技艺说明标注真实专属资源上限；作战单位与技能侧栏显示当前数量／上限。谬因升变后显示存活中继设施数量（0生命的充能设施仍计入）；死芒显示仆役数量，维什戴尔另显示重炮弹。自身资源与敌方标记区分：禁言、束缚索等标记不再显示为虚假的自身资源。
5. 普通训练结束进入成长动画，显示提升的指标、实际增加值、前后数值、对应分级、倍率及生命回满提示。熟练度跨过100／200时提示自动专精／升变；物资检整显示实际补给增加，不伪造数值增长。确认后继续准备日，刷新可恢复尚未确认的结果。
6. 攻击增加移动轨迹、单位发力、命中亮度反馈和实际生命／护盾损失跳字，与既有技能特效叠加。支持双方单位与召唤物；视觉数据不参与伤害计算。
7. 我方领袖使用蓝白接入条，敌方领袖使用红黑警戒条，显示姓名与实算分级。博士、剧情领导者／Boss与事件Boss识别为领袖；召唤物与设施不继承领袖身份。中途登场领袖也触发；每名单位每场只播放一次，普通重绘不重复播放。
8. 矢量突破的对手技艺、实力分级为两个独立转盘，各自点击抽取。可以先抽任意一个；已抽结果锁定且保存，完成两者才能点击开战。程序模拟入口保留自动完成尚未抽取项目的兼容行为。
9. 全部转盘采用同一连续速度曲线：前12%时间加速，至40%时间匀速，后60%持续减速，末帧精确落在实际结果；取消原末段回摆。完整动效3.9秒，简化动效0.45秒；减少动态设置同步影响成长、攻击与入场动画。
