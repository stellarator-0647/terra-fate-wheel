# BGM接入与验收 v25.3

新增明日方舟主页“视野”场景的《生命流》。原曲由塞壬唱片-MSR发布；对应关系见[PRTS首页场景一览](https://prts.wiki/w/首页场景一览)，曲目和音源来自[塞壬唱片官方页面](https://monster-siren.hypergryph.com/music/232202)。文件来源和权属说明保存在 `dist/assets/music/sources.json`。

## 使用

- 首次点击游戏界面或使用Enter/空格操作后开始播放，遵循浏览器的音频播放规则。
- 默认音量25%，循环播放；顶部BGM按钮打开播放开关、音量滑块和曲目来源。
- 音乐开关和音量独立保存，不修改游戏存档或随机种子。
- 页面内部切换、抽取转盘、战斗重绘不重建音频，避免不断从头播放。
- 页面进入后台时暂停，返回时按已保存的开关设置恢复。
- 音频加载失败时显示“加载失败”及重试按钮。
- 原生音频随网站部署，避免官方CDN临时链接到期后无法播放。
