# 原生图标、档案排版与规则说明 v27

## 本轮修改

### 图标

检查标题、档案、图鉴、成长、作战演出和结局页面的图标入口。删除原先标题的 CSS 三斜线、演出中的自制几何印章，以及结局 Boss 卡的斜杠占位。改用 PRTS 原生职业图标和罗德岛标志。功能性指针、展开箭头、进度条和攻击轨迹保留。

| 使用位置 | 原生素材 |
|---|---|
| 生理耐受、休整 | 医疗职业图标 |
| 物理强度、防御 | 重装职业图标 |
| 战斗技巧、体术 | 近卫职业图标 |
| 源石技艺 | 中坚术师分支图标 |
| 适应性、技力 | 辅助职业图标 |
| 准备日 | 先锋职业图标 |
| 矢量突破 | 特种职业图标 |
| 作战标题、未知阵营 Boss 战果 | 狙击职业图标 |
| 通用档案、栏目与作战结算印章 | 罗德岛标志 |

图标表示当前界面的用途，不代表角色获得该职业。来源：[PRTS 文件一览](https://prts.wiki/w/PRTS:文件一览)，新增的[医疗](https://prts.wiki/w/文件:图标_职业_医疗.png)和[先锋](https://prts.wiki/w/文件:图标_职业_先锋.png)已下载到站内，访问页面不依赖外链。精确素材 URL 和文件大小见 `dist/assets/prts/sources.json`。

### 数值档案

完整档案采用双列卡片，每项依次显示名称、数值、分级。数字不换行，分级字母和名称分开排版，名称不再被数字挤成竖排。浅色卡片的名称及分级改为深色文字。

战斗内的简明档案采用两行三列，六项数值与字母分级可同时显示。完整名称和分级可在“详情”查看。手机端的专属资源继续显示在角色卡及技能栏。

### 规则

默认先说明本场任务、退场后的胜负判定和四种行动。补给、初始属性、成长、熟练度、控制及存档规则按需展开，伤害公式再单独展开。用实际行动和数值描述规则，删去连续大段说明；已核对感染身份、沉默、回能、治疗、护盾、专精及升变规则。

### 领袖

按本轮追加指令，所有我方单位均不判定为领袖。玩家、阿米娅、Ace、携带 Boss 原型或旧档领袖字段的友方都不显示领袖标签，不播放领袖入场。敌方领袖保留屏幕中央、周边暗淡、红色题字和两秒可关闭演出。
