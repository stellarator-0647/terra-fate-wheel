# 高亮配色修正 v27.1

修正转盘选中、浏览和抽取结果在浅色底上的浅金文字。原因是旧版文字颜色选择器优先级高于主题的默认文字颜色。

- 高亮选项改为深蓝文字，编号和概率使用稍浅的深蓝。
- 结果卡的名称、说明统一使用深色文字。
- 悬停保留浅色背景；键盘焦点使用深色描边。
- 修正选项列表标题的展开箭头对比度。

在实际浏览器检查 1366×900 电脑与 390×844 手机，覆盖选中、浏览、悬停、键盘焦点及返回抽取结果。浏览器没有记录脚本错误。

| 文本 | 实测文字与底色对比度 |
|---|---|
| 高亮选项名称 | 9.29:1 |
| 高亮选项悬停名称 | 8.36:1 |
| 高亮编号与概率 | 5.53:1 |
| 悬停编号与概率 | 4.97:1 |
| 结果卡名称 | 10.57:1 |
| 结果卡说明 | 5.11:1 |

实测数据见交付包“验收证据/contrast-qa.json”。本轮仅调整 CSS 配色和版本说明；战斗、随机抽取、概率及存档逻辑未改。没有重复运行战斗回归，v27 的 124 项回归记录保留在上一版交付中。
