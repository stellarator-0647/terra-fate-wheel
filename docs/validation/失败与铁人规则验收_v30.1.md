## 规则

- 剧情作战未达成目标或全队覆灭，直接结束本局；不重试、不跳过失败节点。
- 铁人模式默认关闭；开启后自身最终阵亡即判负，包括矢量突破。即时复活成功、仍有生命时不算最终阵亡。
- 常规模式自身阵亡后，存活队友、召唤物可继续完成任务，胜利仍获成长与战后救援。
- 常规矢量突破未通过可继续准备；模拟作战失败独立结算。
- 待结算旧版失败记录在读取时直接进入结局，旧版活跃铁人战斗同步新规则。已结束的历史档案保留原记录。
