# PRTS 动效与技能彩蛋 v21

## 动效方向与交互

使用原创建模的战术几何、细线、定点标记、扫描开场、冷色终端与琥珀数字。不搬运游戏立绘、视频、音频或官方UI素材。轮盘沿用完整扇区、加速减速、停盘回弹与拨针反馈；本次增加的动效不替代或改变转盘抽取。

- 开场：PRTS连接提示；进入每场作战时阵列自上而下展开，并提示实际任务名。
- 攻击：从施法者至实际命中单位的轨迹、目标标记与卡框反馈。普通伤害、控制和支援都有通用反馈。
- 专属几何：天火斜落陨线，巫恋针脚，缪尔赛思嵌套复制框，伊芙利特推进热带，莫斯提马逆向钟面，真言电路，菲亚梅塔弹道，提丰锁定斩线，扎罗契约菱形，克丽斯腾轨道刻度，利刃裁决印，朔折叠框。
- 胜利：作战成功提示、档案写入；六项真实数值由旧值增长至新值，显示净增幅，熟练度与评级突破同步出现。奖励只结算一次。
- 结局：成功归档或行动终止，显示真实战役历史、熟练度和准备日；不捏造通关结果。
- 动效覆盖层始终 `pointer-events:none`，不抢焦点，不阻塞回合。控件文字不被旋转或缩放。彩蛋按钮可以关闭字幕；转盘的“少动态”同时停用粒子，系统减少动态偏好也生效。

## 朔的资料与改编边界

[PRTS朔壳](https://prts.wiki/w/朔壳)载有暴武、醉生、溯律、描躯；[敛傲](https://prts.wiki/w/敛傲)说明其接近目标后自毁。隐藏技艺是把这些机制改编成回合制，不是把朔壳的原作数值直接搬入本游戏。源为“朔（朔壳原型）”，与现有重岳分开；集中名称审阅中列出。宿傲增生、敛傲自毁与身形护主保留原型意图；百分比、技力、行动速度与四回合门槛均为本游戏设计。
