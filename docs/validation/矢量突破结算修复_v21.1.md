# 矢量突破结算修复 v21.1

原因：VECTOR训练场误用了剧情默认12轮目标期限，双方尚存活时也会因超时判为未通过。

修复：VECTOR独立胜负规则。击败敌方全部活动战斗单位（含召唤物）成功；博士倒下或主动终止失败；不再应用12轮剧情期限。120轮仅作为防僵局上限，18轮起仍有全局力竭。失败记录显示原因。

成长：胜利五项指标各增加 max(2, floor(对手分级锚点×4.5%))×天赋倍率，王庭以上仍遵守实战突破门槛。生理耐受换算生命，适应性换算魔抗／技力，其余为对应属性。熟练度增加3+floor(对手分级序号/4)，不乘天赋，最多200。失败两者均不增加。训练消耗抽签时的一个准备日，不消耗补给；训练后恢复训练前正式生命，再计入成长带来的生命上限变化。不能重复结算。

旧存档：尚未结算的VECTOR更新上限；若只是旧12轮超时且双方仍活着，恢复战斗。已结算的旧失败因战斗快照已经清除，无法自动重建，不补发未经胜利的奖励。

验收：75项测试全部通过，包含12/13/119轮继续、13轮击败后成长仅一次、120轮防僵局、死亡不结束铁人旅程、旧超时恢复和剧情期限不变。实际浏览器导入第12轮双方存活测试档案，执行休整后战斗仍可继续；截图与构造存档放在验收证据中。
