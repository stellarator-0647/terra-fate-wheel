# GitHub 项目与意见反馈验收 v30

日期：2026-10-03。版本：1.30.0。

## 功能

- 首页顶部导航和建角按钮旁新增“意见反馈”，打开游戏内意见页面。
- 表单提供类型、标题、内容和设备；草稿保存在当前浏览器。生成草稿后前往 GitHub，由玩家登录并确认发布。不会自动提交或附带旅程存档。
- 可复制反馈，查看已有意见；长内容超过安全链接长度时明确引导复制粘贴，保留完整本地内容。
- 进入结局时自动弹出致谢：原咒术回战网页游戏链接、GitHub 项目链接与免费 Star 邀请。可关闭继续阅读结局，也可由“项目与致谢”再次打开。
- 项目整理为公开 GitHub 仓库，包含游戏、测试、工具、部署脚本、素材来源、反馈模板和开发说明。

## 验收

- 完整127项测试通过，0失败：原124项回归及反馈URL编码、长文本处理、草稿HTML转义3项测试。
- 浏览器实际操作：首页进入意见页，填写生成草稿，链接含完整中文内容并指向实际项目；390×844无横向溢出，输入文字使用深色，浅色底可读。
- 独立 localhost 导入已有真实模型产出的四场结局验收档案，自动致谢弹窗可见；关闭后保留完整旅程归档，再次打开可用。未覆盖线上玩家存档。
- 手机弹窗全部按钮在屏幕内，来源与项目链接目标正确。
- 本轮未改战斗数值、隐藏概率或存档版本。

GitHub 上传和 Cloudflare 公网部署结果分别保存在本轮发布包中。界面验收使用浏览器尺寸模拟，不作为实体手机或大陆网络新测试结论。
