# 手机适配验收 v28

日期：2026-10-03。版本：1.28.0。

## 修复内容

- 普通转盘改为页面滚动，不再以内部滚动边界阻断上滑。放大盘面保留横向、纵向查看，完整选项列表可以独立滚动并继续向页面传递边界滚动。
- 手机作战保留敌我两列阵列，卡片右上角使用简明字母评级；完整中文分级保留在提示和档案。队友、召唤物仍自动行动。
- 技能、档案、作战记录改为同一阅读区域的三个标签。技能 A/B/C 可独立查看，点击预览不会释放；长技能支持全文阅读。正式行动按钮仍直接释放。
- 六个行动按钮采用三列两行，补给、协同与辅助选项置于可展开菜单。使用补给的原有规则保留。
- 390×844 档案面板可直接显示六项战斗数值及各自评级。更小屏幕使用面板内滚动及“详情”查看完整内容，不压缩成难读的文字。
- 横屏重新分配阵列和阅读面板。窗口尺寸变化不会把桌面补给菜单的打开状态带到手机。队友自动行动时保留阵列及阅读面板的滚动位置。
- 关闭任务或技能说明后保留进入说明前的暂停状态。

## 验收证据

本轮用 Codex 浏览器设置手机尺寸验收，未声称测试了实体 iPhone／Android 设备。浏览器操作记录与图片位于 `artifacts/v28`，测试使用独立 localhost 来源的真实初始抽取档案；未覆盖公开站点的旅程存档。
