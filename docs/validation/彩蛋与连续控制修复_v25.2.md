## 控制规则与原因

发现两种循环：硬控状态不断刷新导致永远不到自然结束；多人扣行动条让受控者始终不到100，按自身机会计算的负面效果也一直不能到期。

1. **硬控连续跳过最多2次自身机会。** 达到该限制，清除冻结、眩晕、睡眠，给予后续2次机会硬控保护。正常短硬控到期时也获得保护。
2. **敌方扣条的压制期限不再刷新。** 第一次发生真实扣条时，记录自上一行动机会起200作战时间的恢复期限。反复扣条、麻痹清空行动条、推条真伤、裂片/重炮等扣条共用此机制。
3. **期限到达时“控制脱离”。** 清除硬控，行动条至少100，并优先安排这次机会；接下来2次机会免疫硬控，直到完成下次机会免疫敌方扣条。状态与原因写入角色卡和作战记录。
4. **敌我统一。** 一人成军、主线、矢量突破、召唤物、敌方都适用。不能靠己方多人永远控制敌方Boss。没有受到敌方扣条时不提前获得机会；自身支付行动条仍有效。
5. 沉默仍仅阻止ABC；恐惧、神经损伤仍按原限制执行，休整/防御仍可用。本机制不提供无敌，不防伤害、阵亡、正常封存或强制退场。
6. 旧存档没有新计时字段时，在接下来首次推进战斗时初始化；首次真实扣条再建立恢复期限，不根据缺失历史补造判定。

说明：200作战时间是2个标准战场轮的时长；不是“每个敌人行动两次”或“玩家已经行动两次”。硬控跳过上限与扣条恢复期限分别计数，避免相互刷新造成循环。
